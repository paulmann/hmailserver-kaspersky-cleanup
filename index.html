hmailserver-kaspersky-cleanup

Scan report first, deletion second

Kaspersky avp.com audits an hMailServer store in report-only mode; you review the findings and delete only confirmed infected messages through the hMailServer COM API. Field-tested PowerShell 7.

What it does

  • Report-only scan, deletion only after review
  • COM API keeps database and files in sync
  • Field-tested against Kaspersky 21.25
